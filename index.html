FIRESTORE GUIDE

FIRESTORE 데이터베이스 권한 안내

Firebase 콘솔에서 새로 생성된 Firestore 데이터베이스는 기본적으로 보안을 위해 모든 읽기/쓰기가 차단되어 있습니다. 데이터를 정상적으로 클라우드에 저장하고 실시간 동기화하려면 규칙을 변경해야 합니다.

Firestore Security Rules (콘솔 규칙 탭에 입력)
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
